# ATM Machine Web Application

A web-based ATM simulator application built using Java Servlets, JSP, HTML, and CSS.

## Features
- Check account balance / deposit / withdraw operations
- Responsive UI using HTML & CSS
- Dynamic response handling using JSP & Java Servlets

## Tech Stack
- **Frontend:** HTML, CSS
- **Backend:** Java (Servlets, JSP)
- **Server:** Apache Tomcat
